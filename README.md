# AI Automation in Private Banking Sector Analysis

## Project Overview
This project explores how AI and automation can improve equity research and wealth management activities. Developed during my Equity Research Internship at Aditya Birla Capital, the project focused on automating repetitive financial calculations, portfolio analysis, and report generation for the private banking sector.

## Objectives
- Automate Private Banking Index calculations.
- Support the identification of Value Picks and Growth Picks.
- Simplify portfolio valuation, NAV calculation, and return analysis.
- Explore AI-driven financial reporting and workflow automation.

## Tools & Technologies Used
- **Custom GPTs:** Generated structured banking sector analysis, stock selection summaries, NAV reports, and portfolio performance reports.
- **Python:** Automated stock price retrieval, index calculations, portfolio valuation, NAV calculation, and return analysis.
- **Google Sheets:** Stored and organized banking stock data, portfolio weights, and calculations.
- **Make.com:** Designed a workflow connecting Google Sheets with OpenAI for automated analysis and report generation.

## Key Learnings
- Learned how to apply AI tools to practical equity research and wealth management tasks.
- Gained hands-on experience with Python-based financial calculations and portfolio analysis.
- Understood how index construction, portfolio weights, NAV, and returns can be incorporated into automated workflows.
- Explored the integration of Google Sheets, OpenAI, and Make.com to reduce manual work.
- Learned the importance of validating AI-generated outputs against manual calculations.
- Understood real-world automation challenges, including API billing requirements, integration limitations, and deployment constraints.

## Implementation & Limitations
The Custom GPT and Python approaches were tested using actual project data. The Make.com workflow successfully connected to Google Sheets, and the OpenAI API connection was configured. However, the complete workflow could not be executed because API billing credits were required.

The project achieved **Level 1 – Demonstrated in Context**. It served as a proof of concept for AI-assisted financial analysis rather than a fully deployed, end-to-end automation system.

## Key Takeaway
This project helped me understand how financial knowledge, programming, and AI can work together to improve the efficiency of equity research. It also taught me that successful automation requires not only a working model but also accurate data, validation, reliable integrations, and practical deployment planning.
